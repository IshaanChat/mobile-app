# Venturo — iOS

Native SwiftUI client. Replaces `mobile/`, which is kept as a reference for the
API contract and is neither built nor shipped.

## Creating the Xcode project (once, on the Mac)

The `.xcodeproj` is not in this repo yet because it has to be generated by
Xcode — a hand-written `project.pbxproj` is not worth the risk. Everything
around it is here already.

1. **Check Xcode is 26 or newer.** Clerk's Swift SDK is built with
   swift-tools-version 6.2 and will not resolve on older toolchains. This is
   the one prerequisite that would change the plan.
   ```
   xcodebuild -version
   ```
2. Xcode → **File → New → Project → iOS → App**.
   - Product Name: **Venturo**
   - Interface: **SwiftUI**, Language: **Swift**
   - Organization Identifier: **com.ishaanchaturvedi** so the bundle id comes
     out as `com.ishaanchaturvedi.salesmechanic`
   - Save into the repo's `ios/` directory.

   > The bundle id must be exactly `com.ishaanchaturvedi.salesmechanic`. It is
   > already registered with Apple, already carries the distribution
   > certificate created on 2026‑07‑29, and already has Sign In with Apple
   > enabled as a capability. A new id means redoing all of it.

3. Set **Minimum Deployment** to **iOS 17.0**.
4. Xcode 16+ uses synchronized folder groups, so the files already in
   `ios/Venturo/` are picked up automatically. If your project shows them as
   plain folders instead, right-click → **Add Files to "Venturo"** with *Copy
   items if needed* **unchecked** — they are already in place.
5. **Register the fonts.** Target → **Info** → add **Fonts provided by
   application** (`UIAppFonts`) with these seven entries:
   ```
   Fonts/Fraunces_400Regular.ttf
   Fonts/Fraunces_600SemiBold.ttf
   Fonts/PlusJakartaSans_400Regular.ttf
   Fonts/PlusJakartaSans_500Medium.ttf
   Fonts/PlusJakartaSans_600SemiBold.ttf
   Fonts/PlusJakartaSans_700Bold.ttf
   Fonts/Baloo2_500Medium.ttf
   ```
   Then open `DesignSystem/Theme.swift` and run the **Fonts** preview. Every
   row must show ✓. A missing entry falls back to the system font *silently*,
   which reads as "the design looks slightly wrong" rather than as an error —
   check it once here and you never have to wonder later.

6. **App icon.** `Resources/AppIcon-1024.png` is already full-bleed, opaque and
   1024². Drag it into the 1024 slot of `AppIcon` in the asset catalogue. Do
   not round its corners — iOS masks its own squircle, and the source art's
   baked-in rounding and border were removed for exactly this reason.

## Conventions

- **Colour comes from `@Environment(\.theme)`**, never a literal. The accent is
  two different purples by design — light `#6E4EAB`, dark `#D0B8F0` — because
  the icon's lavender measures 1.64:1 on the light background and is unusable
  there. A hardcoded hex will be wrong in one mode.
- **Type comes from `TextStyle`**, and never pairs a custom family with
  `.fontWeight()`. Each weight is a separate registered family; asking for a
  weight the family does not ship gets a synthesised approximation.
- **The prototype is the design source of truth.** Run it from `server/`:
  ```
  npm run app:preview        # http://localhost:4300
  ```
  When this app and the prototype disagree, the prototype is right.

## The API

Base: `https://sales-mechanic-api.onrender.com/api`. Auth is a Clerk session
JWT as `Authorization: Bearer <jwt>`.

`mobile/src/api/client.ts` and `mobile/src/types/index.ts` are the working
specification for all 20 live endpoints — read those rather than re-deriving
shapes from the Express routes.

Four things that will crash a naive Swift client:

| | |
|---|---|
| Dates carry fractional seconds | `JSONDecoder.DateDecodingStrategy.iso8601` **rejects them and throws**. Use `.custom` with `ISO8601DateFormatter` and `.withFractionalSeconds`. |
| `GET /profile` | Returns **200 with a literal `null` body** for a new account. Decode `UserProfile?`. |
| `DELETE /trends/:id/save` | Returns **204, empty**. Do not decode. |
| Clerk tokens last ~60s | Fetch per request via `await clerk.auth.getToken()`. A stored string 401s after a minute idle. |

Also: the free Render tier cold-starts in ~30s, so set
`timeoutIntervalForRequest` well above 60 and show the waking-up copy.
